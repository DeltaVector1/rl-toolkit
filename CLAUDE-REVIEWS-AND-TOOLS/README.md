# Claude reviews and tools

Independent reviews of the Xiaomi MiMo environment port (Code, General, Music), written by
Claude as a reviewer. Claude did not write the environment code.

- `CLAUDE-REVIEW-1.md` to `CLAUDE-REVIEW-8.md`: the reviews in order. Review 8 (commit
  `8567350a`) is the latest; its verdict is "Good. Ready to use."
- `claude-review-probe-tooling/`: the probe scripts used to check the environments live on
  Prime sandboxes. Its own `README.md` explains each script and review.
- `claude-review-probe-tooling/results/`: the raw probe output the reviews quote.

The scripts are review aids, not part of the environments or the test suite.
